## 1. 개요 (Intent & The Why)
* **목적**: 
  1. 기존 우리말 맞춤법 퀴즈에 더해 **한자(漢字) 및 고사성어 퀴즈 모드**를 도입하여 학습 영역 확장.
  2. "하루 5문제 고정으로 인한 단조로움"을 해소하기 위해 5문제 만점(5/5 정답) 달성 시 다음 라운드(새 5문제)로 끊김 없이 이어지는 **연속 라운드 시스템** 구축.
  3. 랭킹 시스템 내 하드코딩된 **더미 가짜 계정(체리블라썸, 토끼마카롱 등)을 전면 제거**하고 실제 활동 유저 기반의 실시간 랭킹 체계 확립.
  4. 회원 로그인 및 활동 시 접속 IP, 시각(KST), 디바이스 정보(User-Agent) 등을 서버에 보관하는 **접속/이용 이력 감사 로그** 신설.
  5. 시놀로지 NAS Portainer 및 GitHub 레포지토리 간의 **실시간 쌍방향 형상 동기화**와 `기술레포트.md`, `제작히스토리.md` 표준 문서화 준수.

## 2. 목표 (Goals), 비목표 (Non-Goals), 안티골 (Anti-Goals)

### 2.1 목표 (Goals)
* **모드 전환 UI**: 메인 홈 화면 상단에 직관적인 `[🌸 우리말 맞춤법] ⇄ [📜 한자·고사성어]` 토글 스위치 배치 및 테마 연동.
* **한자 퀴즈 엔진 & 사전 연동**:
  * 한자 전용 문제은행 모듈(`hanja_questions.js`) 신설 (사자성어, 동음이의어, 일상 한자어).
  * 문항별 **정답 한자, 음과 훈, 단어 용례(Usage), 실생활 예문(Examples)** 제공.
  * 국립국어원 표준국어대사전 Open API 및 네이버 한자사전 딥링크(1클릭 검색) 연동.
* **연속 라운드 시스템 (VOC 해결)**:
  * 1회차 5문제를 만점(5/5 정답)으로 통과하면 결과 화면에 **"🎉 만점 달성! 다음 라운드 도전하기 🔥"** 버튼 노출.
  * 1라운드 만점(100점) 달성 시 일일 출석 및 오늘 점수 100점 확정, 2라운드부터는 클리어 시마다 **추가 보너스 포인트(+50P)**가 누적 포인트(`totalPoints`)에 적립되고 프로필/랭킹에 최고 도달 라운드 뱃지(예: `🔥 3라운드 돌파`) 표시.
* **가짜 아이디 영구 퇴출 & 실시간 랭킹**:
  * 프론트엔드의 가짜 유저 생성 코드(`generatePeerRankings`) 및 로컬스토리지 잔재 완전 삭제.
  * `/api/leaderboard` 엔드포인트를 통해 서버 DB(`data/users.json`)의 실제 유저 목록만 반영.
* **접속/이용 이력 서버 관리 및 권한 모델**:
  * `data/access_logs.json`에 로그인 성공/실패, 라운드 클리어, IP, 접속 일시(KST), User-Agent 기록.
  * 일반 회원은 프로필 모달 내 "📋 내 접속/이용 이력"에서 본인 기록 열람.
  * 대표 관리자 계정(`단민러브`)으로 로그인 시 **"[👑 전체 회원 접속 감사 로그]"** 메뉴가 활성화되어 전 회원 감사 로그 조회 가능.
* **배포 및 문서화**:
  * GitHub `mkotinet/Spelling` 레포지토리에 푸시 및 시놀로지 Portainer `spelling` 컨테이너 재배포/동기화.
  * `기술레포트.md`와 `제작히스토리.md` 최신화.

### 2.2 비목표 (Non-Goals)
* 별도의 도메인이나 독립된 서브도메인 앱으로 분리하지 않고 `haru.danminlove.com` 단일 앱 내에서 매끄럽게 모드 전환 지원.
* 유료 한자 상용 API 결제 없이 오픈 API 및 고품질 자체 문제은행과 네이버 딥링크로 비용 없이 구현.

### 2.3 안티골 (Anti-Goals)
* 기존 사용자의 누적 포인트, 출석 스트릭, 획득 뱃지 등 기존 데이터 유실 방지.
* 매 문제 클릭마다 서버 딜레이가 생겨 경쾌한 퀴즈 인터랙션(효과음, 콤보 연출)이 끊기는 일 방지.

## 3. 제약 사항 (Constraints)
* **런타임 환경**: 시놀로지 NAS Docker 컨테이너 (`node:20-alpine`, Node.js 내장 모듈 기반).

* **네트워크**: NPM(Nginx Proxy Manager)을 통해 `haru.danminlove.com` (443 포트, SSL/TLS) -> 호스트 포트 8089 매핑.

### 5.3 5문제 만점 시 연속 라운드 메커니즘 (사용자 결정 1-A 반영)
* 판정 기준: 5문제 중 5문제 모두 정답 (`correctCount === 5`).
* 라운드 1 완료: 일일 출석 도장 기록 및 `todayScore = 100` 확정.
* 라운드 2 이상: 
  * 만점 클리어 시마다 `currentRound++`, 보너스 점수 `+50P`를 `totalPoints`에 즉각 가산.
  * 유저 정보에 `maxRoundToday` 갱신.
  * 랭킹 카드 및 프로필에 `🔥 N라운드 돌파` 뱃지 렌더링.
* 오답 발생 시: 라운드 종료 및 오답 복습 노출 ("해당 라운드 재도전하기" 또는 "홈으로").

### 5.4 가짜 아이디 제거 및 클린 랭킹 연동
* `app.js`의 `generatePeerRankings()` 함수 완전 제거.
* `DataManager.load()` 실행 시 기존 로컬 스토리지에 남아있던 `peer_1` ~ `peer_7` 더미 데이터를 자동 필터링하여 영구 정제.
* 랭킹 탭 진입 시 `/api/leaderboard`를 비동기 호출하여 시놀로지 서버 DB(`data/users.json`)의 실제 사용자 목록으로 실시간 정렬 및 렌더링.

### 5.5 로그인 및 이용 기록 관리 & 인가 체계 (사용자 결정 2-A 반영)
* 저장소: `data/access_logs.json` (최근 1,000건 유지 로테이션)
* 기록 항목:
  ```json
  {
    "id": "log_1794408100123",
    "timestamp": "2026-11-14T15:55:00.000Z",
    "kstTime": "2026-11-15 00:55:00",
    "username": "단민러브",
    "action": "LOGIN_SUCCESS", // LOGIN_SUCCESS, LOGIN_FAIL, REGISTER, ROUND_CLEAR
    "ip": "192.168.1.100",
    "userAgent": "Mozilla/5.0 ...",
    "details": { "mode": "hanja", "round": 2, "score": 100 }
  }
  ```
* 신규 API:
  * `GET /api/user/logs`: 현재 로그인된 유저의 최근 30건 이용 기록 조회 (본인 인증 토큰 필요)
  * `GET /api/admin/logs`: 전체 사용자 접속 감사 로그 조회 (`단민러브` 계정 토큰 검증 필요)
* UI 연동:
  * 모든 유저: 프로필 모달 내 "📋 내 접속/이용 이력" 탭 제공.
  * `단민러브` 계정: 프로필 모달에 **"[👑 전체 회원 감사 로그]"** 버튼 활성화 및 전용 로그 뷰어 모달 제공.
