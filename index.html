📲 홈 화면에 바로가기 앱 추가

하루맞춤 앱을 홈 화면에 추가해보세요!

앱스토어 설치 없이 홈 화면에서 진짜 앱처럼 빠르게 실행하고 실시간 알림을 받을 수 있어요.

🍎 아이폰 / 아이패드 (iOS Safari)
  1. 화면 하단 중앙의 공유 버튼(􀈂 또는 [공유])을 누릅니다.
  2. 메뉴를 아래로 내려 '홈 화면에 추가' 항목을 선택합니다.
  3. 우측 상단의 '추가'를 누르면 홈 화면에 예쁜 하루맞춤 아이콘 앱이 생성됩니다!
  4. 홈 화면의 하루맞춤 앱을 실행한 후 우체통(📬)에서 '알림 켜기'를 누르면 끝!
🤖 안드로이드 (Galaxy / Chrome)
  1. 상단 브라우저의 '앱 설치' 또는 우측 상단 더보기(⋮)를 누릅니다.
  2. '홈 화면에 추가' 또는 '앱 설치'를 누릅니다.
  3. 홈 화면에 추가된 앱을 열고 '알림 허용'을 누르면 백그라운드 푸시와 알림음이 작동합니다!
